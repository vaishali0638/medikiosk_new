# kiosk_flutter

The patient-facing MediKiosk client. Android 12+, run in Android Enterprise dedicated-device
(lock-task) mode.

## First-time setup

The Android host project is generated by the Flutter tool rather than committed by hand.
Requires Flutter 3.27 or newer (the theme uses the current `Color` component API). With the
Flutter SDK on your PATH, run once from this directory:

```bash
flutter create --platforms=android --org org.medikiosk --project-name medikiosk_kiosk .
```

That fills in `android/` without touching `lib/`, `test/`, `pubspec.yaml` or
`analysis_options.yaml`. Phase 3 then configures lock-task mode, `FLAG_SECURE` and the
MDM provisioning profile.

## Checks

```bash
flutter pub get
flutter analyze
flutter test
```

## Theme

`lib/theme/design_tokens.dart` is **generated** from `packages/design_tokens/src/tokens.ts`.
Do not edit it; run `npm run tokens:build` from the repository root instead.
