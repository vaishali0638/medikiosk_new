# kiosk_flutter

The patient-facing MediKiosk client. Android 12+, run in Android Enterprise
dedicated-device (lock-task) mode.

Requires **Flutter 3.27 or newer** — the theme uses the current `Color` component API.

## First-time setup

The Gradle scaffolding under `android/` is generated by the Flutter tool rather than
committed. The MediKiosk-specific Android sources **are** committed, and `flutter create`
overwrites templated files, so restore them afterwards:

```bash
flutter create --platforms=android --org org.medikiosk --project-name medikiosk_kiosk .
git checkout -- android/app/src/main/AndroidManifest.xml android/app/src/main/kotlin android/app/src/main/res/xml
flutter pub get
```

The restored files are the ones that make this a kiosk rather than an app:

| File | Purpose |
|---|---|
| `MainActivity.kt` | Lock-task mode, `FLAG_SECURE`, inert Back button, lock-state channel |
| `KioskDeviceAdminReceiver.kt` | Device-owner receiver for Android Enterprise provisioning |
| `AndroidManifest.xml` | `HOME` intent filter so a reboot returns here; backup disabled |
| `res/xml/device_admin.xml` | Device administration policies |
| `res/xml/data_extraction_rules.xml` | No cloud backup, no device-to-device transfer |

## Running against a local backend

```bash
flutter run \
  --dart-define=MEDIKIOSK_API_BASE_URL=http://10.0.2.2:3000 \
  --dart-define=MEDIKIOSK_DEVICE_CODE=MK-OPD-01
```

`10.0.2.2` is the host machine as seen from the Android emulator. `MK-OPD-01` is seeded by
`npm run seed -w @medikiosk/core-api`.

On a non-Android target the app reports itself as **not locked down** and shows a staff
warning banner. That is deliberate: a debug build must never look like a secured kiosk.

## Layout

```
lib/api/        Typed HTTP client; correlation id and device code on every request
lib/config/     KioskConfig — what the server says this kiosk may offer
lib/l10n/       Shell strings only. Clinical text is governed content, never here
lib/platform/   Lock-task and FLAG_SECURE, behind an interface so tests can fake it
lib/screens/    Home, language, status screens, exit and timeout dialogs
lib/session/    Session lifecycle, inactivity timers, secure wipe
lib/theme/      Generated design tokens, theme, accessibility scope
lib/widgets/    MkButton, MkScreen — 48 dp targets, large text, high contrast
```

`lib/theme/design_tokens.dart` is **generated** from `packages/design_tokens/src/tokens.ts`.
Do not edit it; run `npm run tokens:build` from the repository root.
